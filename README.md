A backend application focused on transaction integrity, secure authentication, and reliable banking-style transfers.

- Ledger-based transaction design.
- Idempotent transfers to help prevent duplicate transaction processing.
- JWT-based authentication and secure password handling.
- Email notifications for transaction events.

**Tech Stack:** Node.js, Express.js, MongoDB, Mongoose, JWT, Nodemailer.

An application that helps businesses analyze failed payments and identify potential revenue recovery opportunities.

- Failed-payment analysis and failure diagnosis.
- Recovery recommendations and estimates.
- Deterministic policy checks before executing recovery actions.
- Outcome verification and recovered-revenue metrics.

**Tech Stack:** JavaScript, Node.js, Express.js, PostgreSQL, Prisma, AI integrations.

> AI recommends. Deterministic policy decides. The executor executes.
